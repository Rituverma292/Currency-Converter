# 💱 Currency Converter

A responsive Currency Converter website built using HTML, CSS, and JavaScript to convert amounts between different currencies with ease.

## 🌐 Live Demo
[Click here to use the Currency Converter](https://rituverma292.github.io/Currency-Converter/)

## ✨ Features
- 💱 Convert amounts between different currencies
- 🌍 User-friendly currency selection
- ⚡ Fast and interactive conversion
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and simple interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Use
1. Open the website using the Live Demo link.
2. Enter the amount you want to convert.
3. Select the source currency.
4. Select the target currency.
5. Click the convert button to see the converted amount.

## 📂 Project Structure
- `index.html` – Website structure
- `style.css` – Styling and responsive layout
- `script.js` – Currency conversion functionality
